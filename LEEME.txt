MODOFOKERYT Estore — Panel de control de demostración

Archivos: index.html, styles.css y app.js.
Contraseña de demostración: Admin123!

Puedes subir estos archivos a GitHub y desplegarlos en Railway como servicio web estático.
IMPORTANTE:
- Esta demo guarda productos y pedidos en el almacenamiento local del navegador; no se sincronizan con otros dispositivos.
- La contraseña está en el JavaScript visible para los visitantes. No uses esta demo como panel privado real en producción.
- Los pedidos se introducen manualmente; no se verifican pagos ni se entregan archivos automáticamente.
- Para un panel real hace falta backend con autenticación segura, base de datos y conexión mediante webhooks a la plataforma de pago.

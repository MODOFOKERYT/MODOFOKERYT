MODOFOKERYT Estore — tienda + panel de control
================================================

ESTRUCTURA
- index.html, styles.css, script.js: tienda digital (prototipo frontend)
- assets/: recursos de la tienda
- panel-control/index.html: demostración del panel de control

PARA SUBIR A GITHUB
1. Descarga y descomprime este ZIP.
2. En GitHub, crea o abre el repositorio de la tienda.
3. Sube todos los archivos y carpetas de esta carpeta al repositorio.
4. La página principal de la tienda es index.html.
5. El panel está dentro de la carpeta panel-control.

IMPORTANTE — ESTADO DEL PROYECTO
Este paquete reúne los archivos, pero no convierte automáticamente el panel en un servicio privado
ni lo publica con una URL independiente. El panel incluido es solo una demostración frontend:
no uses su contraseña de demostración para proteger información real. Para administración segura
se necesita autenticación validada en un servidor y permisos del lado del servidor.

La tienda original también es un prototipo: no procesa pagos reales, no registra cuentas en un
servidor ni entrega descargas protegidas. Antes de vender, conecta backend, base de datos,
autenticación y pasarela de pago. Revisa productos, precios y datos de contacto.


DISEÑO VISUAL: fondo negro con detalles y botones rojos, tanto en la tienda como en el panel de control.
